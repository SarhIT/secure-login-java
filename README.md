# Secure Login System (Java)

A console-based authentication system built with Java.

## Features
- User registration and login
- Password hashing using SHA-256 with a random salt
- Password strength validation
- Account lockout after 3 failed attempts
- Activity logging (success/failure with timestamps)

## Concepts Used
OOP, file handling, hashing, input validation

## How to Run
Compile and run `Main.java` using any Java IDE (JDK 17+).
